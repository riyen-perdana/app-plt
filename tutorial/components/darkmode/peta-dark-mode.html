Peta Kerja Dark Mode

Tekan putar dan ikuti denyutnya. Titik bercahaya turun lewat penghubung ke kartu berikutnya, lalu baris kode yang dijalankan menyala satu per satu. Warna kartu mengikuti file-nya, jadi Anda bisa mengenali file yang sama di langkah mana pun.

Kode di kartu diambil dari file asli pada commit terakhir, lengkap dengan nomor barisnya. Isi string di theme-script.ts aslinya satu baris panjang, di sini diformat ulang (ditandai ↳) agar terbaca.

Nilai awal di panel keadaan adalah contoh skenario, bukan data nyata dari peramban Anda.
